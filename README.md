# Git Commit Messages

A skill for writing clear, accurate Git commit messages and creating well-scoped commits.

## Capabilities

- Inspect staged and unstaged changes.
- Select an appropriate commit type and scope.
- Write concise imperative subject lines.
- Explain motivation and context in the commit body.
- Add accurate issue and breaking-change references.
- Verify commits and preserve repository history safely.

## Usage

Use when preparing commit messages or committing changes. Follow the repository's existing conventions first. When no convention exists, use Conventional Commits as described in `SKILL.md`.

## Safety

Review staged contents before committing. Do not include secrets, unrelated changes, or unreviewed files. Avoid amending or rewriting shared history without explicit approval.
